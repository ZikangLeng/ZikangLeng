### Hi, I'm Zikang 👋

I'm a Computer Science PhD student at **Georgia Tech**, advised by Prof. Thomas Plötz, and an **NSF Graduate Research Fellow**. I'm currently a Machine Learning Engineer Intern at **BehaviorAI**.

I work on human-centered AI and ubiquitous computing: generating virtual sensor data with LLMs and embodied agents when real data is scarce, and learning from wearable, physiological and behavioral signals to recognise activity and engagement in everyday settings.
